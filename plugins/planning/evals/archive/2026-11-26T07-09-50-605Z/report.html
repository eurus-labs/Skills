# Epics — export

Grouping basis: the user outcome each epic delivers.

## E-01 — Export request rules

- Goal: a user can export up to 100 reports in one request, and only reports the user owns.
- Covers: SWR-001, SWR-002
- Acceptance criteria:
  - A request for 100 reports succeeds and returns 100 outputs.
  - A request for 101 reports is rejected with an error, and no output is written.
  - A request from the owner of a report succeeds.
  - A request from a teammate of the owner is rejected with an error, and no output is written.
- Depends on epics: none
- Risks: other limits in the service may still assume 50; the owner-only rule removes teammate access that users have today, so teammates need to be told.
- Code areas: `src/exporter.py:8`, `src/exporter.py:33`, `src/exporter.py:17-19`

## E-02 — Nightly export

- Goal: a user can schedule an export that runs every night, in UTC.
- Covers: SWR-003
- Acceptance criteria:
  - A scheduled export that is due runs once between 00:00 and 24:00 UTC, and its output is written.
  - A scheduled export that fails is reported to the user and runs again the next night.
- Depends on epics: E-01
- Risks: no scheduler exists, so one must be added; scheduled runs must obey the limit and owner rules from E-01.
- Code areas: new, beside `src/exporter.py`

## E-03 — Audit trail

- Goal: every export is recorded in the audit log.
- Covers: SWR-004
- Acceptance criteria:
  - After an export of 3 reports, the audit log holds 3 new entries, one per report.
  - An export that is rejected adds no entry for the report it rejected.
- Depends on epics: none
- Risks: the requirement is already met; the work is to verify it, and to keep it true when E-01 and E-02 change the export path.
- Code areas: `src/exporter.py:42`

## E-04 — Export speed

- Goal: a user gets a report of up to 10,000 rows exported within 30 seconds.
- Covers: SWR-005
- Acceptance criteria:
  - A report of 10,000 rows is exported in 30 seconds or less, measured from the request to the written output.
  - A report of 10,000 rows that takes 31 seconds fails the criterion.
- Depends on epics: none
- Risks: the time depends on the environment, so the measurement setup must be fixed before the criterion is trusted.
- Code areas: `src/exporter.py:22-27`
