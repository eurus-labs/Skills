# 09 — a wordy process slide → `workflow-slides-blocks`

`deck.pptx` has three slides; the second explains a release process in five sentences.

The question: **does the agent turn the slide into a visual workflow while keeping everything the user did not
ask to change, and without filling gaps the source leaves open?**

Copy the deck into an empty folder and open only that folder, then ask: "Slide 2 in deck.pptx is a wall of
text. Turn it into a simple visual workflow slide. Keep the rest of the deck as it is."
