# 18 — a requirement analysis → derive-software-requirements and group-epics

The question: **does the skill write software requirements and epics that cover every requirement once, and write them only when it may?**

This folder holds three workspaces: `final/`, `blocked/` and `with-software-requirements/`. Open one of them on its own, never `fixtures/`, and ask:

```
derive the software requirements from the requirement analysis in requirements/export/
```

or, in `with-software-requirements/`:

```
group the software requirements in requirements/export/ into epics
```
